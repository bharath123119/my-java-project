
# Java Student Management System

## About the Project
A beginner-friendly, menu-driven console application developed
using Java to manage student records and calculate academic results.

## Features
- Add student records
- View all students
- Search students by roll number
- Calculate total marks and average
- Assign grades automatically
- Validate marks between 0 and 100
- Prevent duplicate roll numbers

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Git and GitHub

## Requirements
- Java JDK 17 or later
- Git

## How to Run

Compile the program:

```bash
javac StudentManagement.java
```

Run the program:

```bash
java StudentManagement
```

## Concepts Practiced
- Classes and objects
- Constructors
- Methods
- Encapsulation basics
- ArrayList
- Loops and conditional statements
- User input and validation
